# 🧭 iContext

**Give AI the context of your codebase in seconds.**

iContext is a lightweight CLI tool that scans your local project and generates a compact diagnostic report for AI assistants.

No API keys required. No cloud uploads. Local-first.

---

## Quick Start
```bash
git clone https://github.com/dulcevenganza666777-lang/icontext-.git
cd icontext-
chmod +x icontext
./icontext
```

## Example
```text
📁 PROJECT: Cronos-V3
📄 FILES: 389
🔤 LANGUAGE: Python
🎯 NEXT ACTION: Review first pending integration
```
